# Cidades Perdidas

Puzzle adventure 3D atmosférico desenvolvido em Unity.

> *Em algum lugar sob a Terra, uma exploradora desperta entre ruínas milenares. O Cristal Memória pulsa nas sombras — colete-o e a passagem se abrirá. Mas algo nas profundezas ainda está vivo.*

## 🎮 Jogar
[Jogar no itch.io](https://carljr-404.itch.io/cidades-perdidas)

## 📖 Sobre o jogo
Cidades Perdidas é um puzzle adventure 3D desenvolvido em 7 dias como projeto solo. O jogador controla uma exploradora em ruínas subterrâneas, coleta o Cristal Memória e escapa pela passagem secreta.

## 🛠️ Tecnologias
- Unity 2022.3
- C#
- WebGL

## 📁 Scripts
| Script | Função |
|--------|--------|
| `MovimentoPersonagem` | Movimentação do personagem com WASD |
| `CameraFollow` | Câmera seguindo o personagem |
| `ColetaArtefato` | Coleta do cristal e abertura da porta |
| `PatrulhaInimigo` | IA do inimigo patrulhando a área |
| `MenuInicial` | Controle do menu principal |

## ⏱️ Desenvolvimento
- **Tempo:** 7 dias
- **Tipo:** Projeto solo
- **Escopo:** Programação, design e ambientação

## 🎮 Controles
- `WASD` — Mover
- `E` — Interagir
